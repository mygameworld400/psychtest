
# 연인 심리·성향·관계패턴 분석 서비스 — MASTER SPEC v1.0

## 0. 한 줄 정의
**성격을 맞히는 테스트가 아니라, 두 사람이 관계에서 어떻게 생각하고 행동하며 충돌하고 회복하는지를 상황형 문항과 자기보고를 통해 분석하는 관계 패턴 서비스.**

이 서비스는 의학적·임상적 진단도구가 아니다. 결과는 자기이해와 대화 촉진을 위한 **성향 지표/관계 신호**로 제공하며, 미래 행동이나 재결합을 확률적으로 예언하지 않는다.

---

# 1. 상품 구조

## PRODUCT 1 — ME
### 목적
본인의 연애스타일·관계행동 패턴을 분석한다.

### 가격 포지션
가장 저렴한 입문 상품.

### 핵심 결과
- 연애 기본 스타일
- 애착/거리 욕구
- 갈등 처리 방식
- 신뢰 기준
- 사랑 표현/수용 방식
- 독립성/통제성
- 돈·생활·미래 가치관
- 스트레스 시 행동
- 관계에서의 강점
- 반복될 수 있는 약점
- "나를 연애할 때 이렇게 다뤄주세요" 사용설명서

### 기본 출력 개수
사용자에게는 8~12개 핵심 지표만 노출.
내부에서는 30개 이상 지표를 계산.

---

## PRODUCT 2 — PERSON
### 목적
추가한 사람의 연애스타일을 분석한다.

### 입력 모드
1. **직접 응답형**: 상대가 링크를 받아 직접 테스트
2. **관찰 추정형**: 사용자가 상대의 행동을 기반으로 답변

### UI 주의
직접 응답형:
> 본인 응답 기반 분석

관찰 추정형:
> 당신이 관찰한 행동을 기반으로 한 추정 분석

둘을 절대 같은 신뢰도로 표현하지 않는다.

### 과금 아이디어
- 본인 1명: 기본
- 추가 인물 1~3명: 본인과 동일한 단가
- 4명째부터: 추가 과금
- 나중에 관계도 그래프 기능으로 확장

---

## PRODUCT 3 — PAIR
### 목적
두 사람의 궁합과 관계 역학을 분석한다.

### 중요
단순 종합궁합 한 점수로 끝내지 않는다.

### 기본 결과
- 감정 궁합
- 갈등 해결 궁합
- 연락/거리 궁합
- 신뢰 기준 궁합
- 생활 리듬 궁합
- 돈/소비 궁합
- 미래 계획 궁합
- 사랑 표현 궁합
- 주도권/의사결정 궁합
- 관계 회복 궁합

### 가장 중요한 추가 결과
**A가 B에게 미치는 영향 / B가 A에게 미치는 영향**

예:
- 정서 안정 +18
- 결정 속도 +24
- 자유도 -12
- 갈등 피로 +9

### 또 중요한 기능
**상대 이해도**
- 내가 예상한 상대 답변
- 상대의 실제 답변
- 일치율
- 특히 크게 오해하는 영역 3개

---

## PRODUCT 4 — NOW
### 대상
권태기, 싸움 반복, 거리두기, 애정 혼란, 관계 피로를 겪는 현재 연인.

### 포지션
고가 정밀 리포트.

### 핵심
내부적으로는 30~50개 상태 지표를 계산하지만,
사용자에게는 **현재 그 사람에게 가장 의미 있는 5~9개만 선별**해서 보여준다.

### 지표 표현
확률이 아니라:
- 상태 지표
- 신호
- 강도
- 경향

예:
- 관계 에너지 방전 86
- 혼자 회복 필요 79
- 누적 서운함 82
- 애정 잔존 74
- 관계 회복 의지 88
- 이별 의사 신호 21

### 핵심 문장 예시
- "헤어지고 싶은 마음보다 쉬고 싶은 마음이 더 강합니다."
- "애정 감소보다 신뢰 손상이 현재 문제의 중심에 가깝습니다."
- "권태라기보다 반복 갈등에 대한 무기력이 더 크게 나타납니다."
- "상대가 싫어진 것보다 관계 속 자신의 모습에 지친 상태에 가깝습니다."

최고가 심층 리포트.

### 핵심 출력

- 외로움 영향
- 미련 잔존
- 과거 관계 미화
- 죄책감
- 분노 잔존
- 연락 충동
- 관계 복구 욕구
- 미해결 감정
- 자존심 회복 욕구
- 상실 불안
- 현재 연락 적정도

# 5. 점수 시스템

## 기본
각 지표는 0~100으로 환산한다.

Likert 1~5 응답:
- 1 = 0
- 2 = 25
- 3 = 50
- 4 = 75
- 5 = 100

역채점 문항은:
100 - 점수

## 권장 방식
한 지표당 최소 3개 문항.
가능하면 4~6개 문항.

### 지표점수
`indicator = weighted_mean(items)`

### 응답 일관성
같은 개념을 다른 표현으로 2번 이상 물어 일관성 확인.
극단적으로 모순되면 신뢰도 낮춤.

### 결과 신뢰도
- 85~100: 응답 일관성 높음
- 70~84: 해석 가능
- 50~69: 혼재된 경향
- <50: 단정적 표현 금지

사용자에게 "정확도" 대신
**응답 일관성** 또는 **분석 신뢰도**라고 표현.

# 6. 개인화 결과 선택 로직

모든 지표를 다 보여주지 않는다.

## 노출 우선순위
1. 80 이상 또는 20 이하의 극단값
2. 커플 간 차이가 30점 이상인 지표
3. 현재 관계 문제와 연관성이 높은 지표
4. 서로 모순되는 흥미로운 조합
5. 사용자가 자유서술에서 반복 언급한 테마

## 한 결과 화면
- 핵심지표 3개
- 중요한 보조지표 2~4개
- 의외의 숨은 지표 1~2개
- 행동가이드 3개

# 7. PAIR 궁합 계산

궁합은 "비슷할수록 무조건 좋다"가 아니다.

## 유사성이 중요한 지표
- 연락욕구
- 개인공간욕구
- 재정관
- 결혼의향
- 자녀의향
- 이성친구/사생활 경계
- 갈등 해결 속도

`similarity = 100 - abs(A-B)`

## 보완성이 가능한 지표
- 주도권욕구
- 계획성/즉흥성
- 문제해결/공감
- 리더십/조율

이 경우 둘 다 극단적으로 같은 방향이면 오히려 마찰 가능.
간격 20~45 정도를 최적구간으로 둘 수 있다.

## 관계 위험도
예:
- A 즉시해결 90 + B 냉각시간 90 → 추격/회피 충돌
- A 투명성요구 90 + B 사생활존중 90 → 경계 충돌
- A 통제욕구 85 + B 자율성 90 → 자율권 충돌
- A 소비 85 + B 저축 90 → 경제 갈등

# 8. NOW 해석 규칙 예시

## "쉬고 싶은 것 vs 헤어지고 싶은 것"
조건:
- 관계에너지방전 >= 75
- 혼자회복욕구 >= 70
- 애정잔존 >= 60
- 관계종료의사 <= 40

출력:
> 현재는 관계를 끝내고 싶은 마음보다 관계에서 잠시 벗어나 회복하고 싶은 욕구가 더 강하게 나타납니다.

## "애정 감소보다 신뢰 손상"
조건:
- 신뢰손상 >= 70
- 애정잔존 >= 60
- 상대말불신 >= 65

출력:
> 애정 자체가 크게 사라졌다기보다, 반복된 사건으로 인해 상대의 말과 행동을 믿기 어려워진 점이 현재 관계의 중심 문제에 가깝습니다.

## "권태보다 무기력"
조건:
- 설렘잔존 <= 40
- 관계무기력 >= 70
- 미해결갈등 >= 65
- 관계회복의지 >= 55

출력:
> 단순한 권태보다 '해도 달라지지 않을 것 같다'는 관계 무기력이 더 크게 나타납니다.

# 9. AFTER 해석 규칙 예시

## "상대보다 공백이 그리운 상태"
조건:
- 재결합욕구 >= 70
- 외로움영향 >= 70
- 생활공백영향 >= 70
- 상대자체애정 <= 55

출력:
> 다시 만나고 싶은 마음은 강하지만, 상대 자체에 대한 애정보다 관계가 사라진 뒤 생긴 공백과 외로움의 영향이 더 크게 나타납니다.

## "사랑은 남았지만 재결합 준비는 낮음"
조건:
- 상대자체애정 >= 70
- 재결합욕구 >= 65
- 과거문제해결가능성 <= 45
- 동일갈등재발위험 >= 70

출력:
> 애정은 남아 있지만, 이별 원인이 해결되지 않은 상태라 지금 다시 만나면 같은 갈등이 반복될 가능성이 높은 구조입니다.

# 10. 동적 추가질문 엔진

고가 상품(NOW/AFTER)은 정적 설문 + 동적 후속질문을 섞는다.

## 트리거 예시

### 모순
"상대를 사랑한다" 5점
"상대와 연락하기 싫다" 5점

추가:
> 상대가 지금 먼저 연락한다면 가장 먼저 드는 감정은 무엇인가요?
- 반가움
- 안도감
- 부담감
- 짜증
- 두려움
- 모르겠다

### 거리두기

# 11. 자유서술 분석 규칙

AI가 자유서술을 분석할 때 추출하는 태그:
- 책임 회피/수용
- 관계 해결 의지
- 분노 강도
- 상대 비난
- 자기 비난
- 통제욕구
- 거리두기
- 애착 표현
- 실용적 해결
- 정서적 공감
- 미래 지향
- 체념
- 반복패턴 언급
- 절대 표현("절대", "무조건", "항상")
- 조건부 표현("~하면", "~일 때만")

AI는 퍼센트를 만들지 않는다.
AI는 이미 계산된 점수와 태그를 바탕으로 설명문만 생성한다.

# 13. 화면 구조

## 홈
- 내 연애스타일 알아보기
- 사람 추가하기
- 궁합 보기
- 현재 관계 정밀진단
- 이별·재결합 심층분석

## ME 결과
1. 한 줄 요약
2. 핵심 지표 6~8개
3. 사랑받는 방식
4. 싸울 때 패턴
5. 관계에서 장점
6. 반복 위험
7. 사용설명서

## PAIR 결과
1. 커플 한 줄 요약
2. 영역별 조화도
3. 가장 잘 맞는 3가지
4. 가장 부딪히는 3가지
5. A→B 영향
6. B→A 영향
7. 서로 오해하는 포인트
8. 싸웠을 때 합의 규칙

## NOW 결과
1. "현재 관계의 중심 상태" 한 문장
2. 핵심 상태지표 5~9개
3. 왜 이렇게 나왔는지
4. 관계가 지치는 방식
5. 내가 상대에게 원하는 것
6. 상대가 압박으로 느낄 수 있는 것
7. 지금 필요한 행동 3개

## AFTER 결과
1. "현재 이별 상태" 한 문장
2. 핵심 상태지표
3. 재결합 욕구의 구성
4. 상대가 그리운 이유
5. 연락 충동 분석
6. 다시 만나도 반복될 위험
7. 지금 감정 정리에 필요한 것

# 16. Claude에 구현 맡길 때 핵심 원칙

1. 질문 텍스트와 계산 로직을 분리한다.
2. 점수 계산은 코드에서 한다.
3. AI는 점수를 임의 생성하지 않는다.
4. AI는 계산된 값과 자유서술 태그를 설명하는 역할만 한다.
5. 질문별 dimension, weight, reverse를 JSON으로 관리한다.
6. 결과 문구도 rule_id 기반으로 관리한다.
7. 버전관리를 위해 모든 설문에 version 필드를 둔다.
8. 유료 리포트 생성 시 사용한 question_version, scoring_version을 저장한다.
9. 관찰 추정형과 직접 응답형은 결과 카드에서 명확히 구분한다.
10. 미래 예측이 아니라 현재 응답 기반 "신호/지표"로 표현한다.

# 18. 개인정보/서비스 신뢰 장치

- 상대의 직접 응답은 본인 동의 없이 제3자에게 세부 원문을 공개하지 않는다.
- 궁합 결과에는 상대의 개별 민감 답변을 그대로 노출하지 않고 요약된 관계 지표만 보여준다.
- 삭제 요청 시 응답 원문과 프로필 삭제 경로 제공.
- 미성년자 대상 성적 친밀감 문항은 분리하거나 비활성화.
- 위기/학대/폭력 관련 응답은 일반 궁합 점수로 소비하지 않고 안전 안내로 분기.

# 20. 결론
이 서비스의 핵심 자산은 질문지가 아니라 **심리 지표 사전 + 점수 규칙 + 개인화 노출 로직**이다.

질문은 계속 교체할 수 있지만,
지표 체계와 계산 모델이 안정적이면 새로운 상품을 계속 만들 수 있다.
